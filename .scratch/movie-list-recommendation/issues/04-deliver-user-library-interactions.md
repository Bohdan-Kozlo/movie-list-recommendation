# 04 — Deliver User Library Interactions

**What to build:** An authenticated user can rate catalogue titles, delete a rating, manage watched history, watchlist, and not-interested state, and observe consistent list transitions.

**Blocked by:** 02 — Deliver Catalogue Discovery; 03 — Deliver Account Authentication and Identity Linking.

**Status:** ready-for-agent

- [ ] Users can create one 0.5-to-5.0 rating per title and delete it without editing it.
- [ ] Marking a title watched or not interested removes it from the watchlist and all interaction changes are visible in the product.
