# Triage Labels

The engineering skills use five canonical roles. This repository uses their default label strings.

| Canonical role | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the ticket. |
| `needs-info` | `needs-info` | Waiting for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When an engineering skill applies a canonical role, it must use the matching local label in this table.
